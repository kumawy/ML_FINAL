# Web presentation

Run `python3 docs/serve.py` from the repository root to open the deck locally. The bundled scripts, fonts and video work offline.

Use the left and right arrow keys to move between slides. Press **P** for presenter notes and a synchronized audience window. Drag the PCA plot on slide 9 to rotate it. Slide 11 switches between error metrics and the full comparison table.

The browser deck has 14 study slides and a closing screen. The [14-page PDF](../presentation/ML_Final_Presentation.pdf) is the static version for submission.

After editing slide markup in `source/parts/`, run `python3 docs/build_deck.py` from the repository root. The build writes the browser entry point and the assembled composition.
